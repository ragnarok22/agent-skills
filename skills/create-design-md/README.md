# Create DESIGN.md Skill

Create an English-only `DESIGN.md` that turns brand strategy and project context into practical design direction for UI, landing pages, visual systems, and implementation.

## Use Cases

- Create a project design guide before building UI.
- Convert `BRANDING.md` into actionable product and landing page rules.
- Define tokens, palettes, typography, spacing, radius, motion, accessibility, and component guidance.
- Give frontend developers and AI coding agents enough direction to build consistent screens.

## Workflow Summary

- Inspect `BRANDING.md`, `README.md`, UI files, theme files, tokens, CSS variables, Tailwind config, and screenshots.
- Ask only 3-6 important missing questions when project context is insufficient.
- Preserve existing brand decisions and avoid generic SaaS design guidance.
- Write a structured, scannable, implementation-friendly `DESIGN.md`.

## Output

- `DESIGN.md` in English, written at the project root unless another location is requested.

## Skill Files

- `SKILL.md`: complete workflow and output structure.
- `agents/openai.yaml`: UI metadata.
